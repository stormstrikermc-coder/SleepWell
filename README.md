# SleepWell

A lightweight Minecraft sleep-voting plugin that gives players a configurable way to skip the night together.

## Overview

SleepWell makes night skipping more flexible for multiplayer servers. Players can vote through chat instead of requiring everyone to enter a bed, while the normal Minecraft bed-sleeping mechanic remains available.

Server owners can tune voting behavior, participation requirements, progress displays, and world-specific settings.

## Features

- **Chat-based voting:** Players can vote yes or no to decide whether the night should be skipped.
- **Configurable vote rules:** Customize vote duration, participation requirements, and voting cooldowns.
- **Normal bed sleeping:** Keep the vanilla sleeping mechanic and configure the required sleep percentage.
- **Live progress:** Display vote progress through an action bar or boss bar.
- **AFK exclusion:** Optionally exclude AFK players from voting.
- **Per-world settings:** Configure sleep behavior separately for individual worlds.
- **Player opt-out:** Let a player opt out of the current night's vote.
- **Lightweight integration:** No mandatory third-party plugin dependencies.

## Installation

1. Download a release compatible with your Minecraft and server version from [Modrinth](https://modrinth.com/project/sleepwell).
2. Place the downloaded JAR in your server's \`plugins\` directory.
3. Restart the server.
4. Review the generated configuration and adjust the voting and sleep behavior to your server.

Do not use a build intended for a different Minecraft or server version.

## Commands

| Command | Description |
| --- | --- |
| \`/sleepwell\` | Show plugin help and status |
| \`/sleepwell vote\` | View the current voting results |
| \`/sleepwell vote yes\` | Vote to skip the night |
| \`/sleepwell vote no\` | Vote against skipping the night |
| \`/sleepwell ignore\` | Opt out of the current night's vote |
| \`/sleepwell reload\` | Reload the configuration |

## Configuration

SleepWell's published feature set includes configuration for:

- Required sleep percentage for normal bed sleeping.
- Voting duration and participation requirements.
- Voting cooldowns.
- Optional AFK-player exclusion.
- Action-bar or boss-bar vote progress.
- Per-world sleep settings.
- Player opt-out behavior.
- Customizable messages.

Use the configuration generated by the plugin as the source of truth for exact option names, defaults, and supported values.
