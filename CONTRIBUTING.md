# Contributing

Thank you for taking the time to contribute.

## Before you start

1. Search existing issues and pull requests to avoid duplicate work.
2. For a substantial change, open an issue first so the proposed direction can be discussed.
3. Keep changes focused. Avoid bundling unrelated fixes or formatting changes.
4. Update documentation when behavior, configuration, commands, or compatibility changes.

## Bug reports

Use the repository's **Bug report** issue form. Include:

- Plugin version.
- Minecraft version and server software.
- Clear reproduction steps.
- Expected and actual behavior.
- Relevant logs or screenshots, with private information removed.

## Feature requests

Use the **Feature request** issue form. Explain the problem the feature would solve, the expected behavior, and any configuration or compatibility implications.

## Pull requests

- Keep the pull request focused and explain why the change is needed.
- Reference the related issue when one exists.
- Describe user-visible behavior changes.
- Include test details and the Minecraft/server versions used.
- Update relevant documentation.
- Do not include server files, credentials, personal data, compiled output, or unrelated dependencies.

## Current repository state

The repository currently contains project documentation and collaboration templates. Source code and build instructions have not yet been added, so implementation changes cannot be reviewed until the source tree is published.
